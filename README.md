# TCP Connect — Private Beta Prototype

**Standalone demo only.** Not part of The Capstone Program website or portal.

## What this is
Student peer-mentoring prototype (learners request sessions from student mentors, dual reporting, demo service hours/certificates).

## What this is NOT
- Not production
- Not connected to Capstone (`thecapstoneprogram.org`) or the admin portal
- Not real authentication, calendar, or official certificates

## Open locally
Open `index.html` in a browser.

## Deploy
Static site — connect this repo to a **new** Vercel project (do not reuse Capstone/portal projects).

## Safety
Keep separate from Capstone repos and domains until a real pilot is approved.
